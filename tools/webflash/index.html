Flash the firmware onto an M5Stack Cardputer ADV from this browser. Version …

  1. Connect the Cardputer to this computer with a USB-C data cable and switch it on.
  2. Press CONNECT, pick the port named USB JTAG/serial debug unit (macOS: cu.usbmodem…, Linux: ttyACM…, Windows: COM…) in the browser's port dialog, then INSTALL.
  3. Keep the dialog open until it says the installation is done (about a minute). The device restarts into the player.

This browser has no Web Serial: use Chrome or Edge on a desktop computer (Firefox and Safari cannot flash), or follow FLASHING.md with esptool. Web Serial only works on an https page or on localhost. Serve this folder with python3 -m http.server 8000 and open http://localhost:8000.

A full install (the "erase" option) wipes the device's flash, not the microSD card; the card content (/lp) stays. Without erase the player's saved settings in flash survive too.

If the port does not show up

  • Use a cable that carries data (some charging cables do not) and a USB port on the computer itself, not a hub.
  • Hold the side button BtnA (G0, the chip's BOOT pin) while plugging the cable in (or while pressing reset): the chip waits in its download mode and the port is then always present. After flashing, press reset or power-cycle.
  • If the device is in USB drive mode (the card shows as a disk), press ENTER on the device first: the drive firmware re-enumerates with a different port that the flasher cannot reset into the bootloader.
  • Linux: your user needs access to the port (sudo usermod -aG dialout $USER, then log in again), and brltty or ModemManager may grab the port — stop them.
  • Close the Arduino serial monitor or any other program that has the port open.

After flashing

The player needs its card content in a folder lp at the root of the microSD card (FAT32): see GETTING_STARTED.md and the manual (MANUAL.md) next to this page in the release, or the repository. The player boots to meehaw / live performer; NO SD CARD means the card or the lp folder is missing.

Flashing by hand instead

pip install esptool
esptool --chip esp32s3 --port PORT --baud 921600 write-flash 0x0 meehaw-player-<ver>-full.bin

FLASHING.md has the port names per system, the update commands and the recovery steps. Miha Ambroz (mihatm8).
